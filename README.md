# 双人节拍

简体中文双人节奏练习，支持随机匹配、邀请房、好友、单人练习和实时语音。适用于手机和桌面浏览器。

## 本地运行

需要 Node.js 22.13 或更高版本，无第三方运行依赖：

```sh
npm start
npm test
```

打开 `http://localhost:3000`。用两个独立的浏览器配置创建和加入同一个房间。双人准备后开始，可调整节拍、暂停、退出并查看自己的对局历史。

## 大厅和观战

- **在线列表**默认不公开你。打开「在线列表 → 我的上线状态和偏好 → 显示我在线」，其他玩家才能在公开列表里看到你。
- **房间列表**只显示已开局、双方都允许公开观战的房间；不显示私人房间，也不代替房间码邀请。准备时的观战选项默认勾选，不想公开请在点准备前取消。
- **旁观**可查看公开房间的节拍和进度。只有双方额外同意公开语音，普通观众才能听见开麦的一方；任一方撤回同意会停止共享。

## 远程联机

参阅 [远程联机部署与排查](docs/deployment.md)：包括 Linux VPS、DNS、Caddy HTTPS、ChatGPT Sites Worker、TURN 以及三人联机验收步骤。

## 语音和好友

- 双向语音需要一方申请、另一方同意；两人分别手动开麦，也可以随时关麦或结束通话。
- 语音优先用 WebRTC 点对点传输；兼容线路通过站点转发短时加密分段。跨网络使用请通过 HTTPS，必要时设置 `TURN_URL`、`TURN_USERNAME`、`TURN_CREDENTIAL`，或用 `TURN_KEY_ID` 和 `TURN_KEY_API_TOKEN` 生成短期凭据。TURN 凭据会发给获准连接的浏览器，不要用长期高权限凭据。
- 赛后可申请加好友。接受后可私信、邀请对局，并可自愿向好友显示在线。默认以当前浏览器的游客身份保存；清除站点数据会丢失该身份。
- 未经双方同意，请勿录制或公开他人的通话。

## 管理后台

设置服务端环境变量 `ADMIN_PASSWORD` 为独立的高强度随机密码，再访问 `/admin`。未设密码时后台不可登录。管理员可查看用户数据、房间状态、流量并处理举报；「查看详情」只显示房间状态，不提供语音、信令或额外观战入口。

在「玩家举报」点「查看举报」展开列表，每页 10 条，可翻页、查看附件、驳回、封禁或解除封禁。

## 自托管与数据

- 默认仅监听 `127.0.0.1:3000`；可用 `HOST`、`PORT` 改动。生产环境通过 HTTPS 反向代理，并设置 `PUBLIC_ORIGIN` 为公开 HTTPS 源地址。不要把 Node 端口直接暴露到公网；请在代理层配置请求和登录限流。代理部署默认只执行账号封禁，不拿代理 IP 作为玩家的网络封禁依据。
- 好友、私信、对局历史、语音试听、流量和举报存储在 `DATA_DIR`（默认 `data/`）下。首次启动会应用 SQLite 迁移。只运行一个实例，保护并定期备份数据目录，禁止记录请求体或管理员 Cookie。服务端可设置持久的 `MODERATION_KEY`，避免重启使旧举报凭证失效。
- 如需跨设备同步好友，可配置独立身份网关：设置随机的 `IDENTITY_PROXY_KEY`，网关必须清除客户端传入的 `X-Duet-Identity-Key` 和 `OAI-Authenticated-User-Id`，并仅对已认证用户的 `/api/friend-identity` 请求注入共享密钥与稳定用户 ID。该通道不能登录后台。默认不依赖 ChatGPT 登录。
- 本仓库不含原站数据、旧提交历史、运行凭据或外部媒体目录，也不连接原站。自行部署时，请为用户数据和举报附件设置留存与删除规则。
